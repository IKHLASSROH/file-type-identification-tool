# File Type Identification Tool



A cybersecurity tool that identifies file types using Magic Numbers and analyzes files using cryptographic hashes.



## Features



-File type detection using Magic Numbers  

- SHA256 hash calculation  

-File size analysis  

-Extension verification  

-Fake extension detection  

-Folder scanning



## Supported File Types



- PNG

- JPEG

- PDF

- ZIP

- Windows Executable
